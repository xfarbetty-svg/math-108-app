## 🎯 核心重構重點（解決人類實機反饋的兩大痛點）

### 痛點一：手機寬度適配（不要再用雙層 20px padding 把手機擠爆！）
- 宣告全域防溢出：
  ```html
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">
  ```
- `html, body { width: 100%; max-width: 100vw; overflow-x: hidden; position: relative; margin: 0; padding: 0; }`
- 外層容器手機專屬內距：`padding: 8px 10px; max-width: 480px; margin: 0 auto; box-sizing: border-box;`。
- **嚴禁雙層 20px padding**！把完整的 370px 空間全部留給教具！
- 實機測量必須保證 `document.body.scrollWidth === window.innerWidth`（在 360px 與 390px 下 0 溢出，頁寬絕對不晃動）。

### 痛點二：徹底告別工程師線框感，全面升級為「日系溫暖繪本擬物風」
- 配色方案：
  - 背景：`--bg: #fff9f0;` 搭配柔和淺橙光暈漸變。
  - 卡片：`--card: #ffffff;` 圓角 `18px`，帶有 `box-shadow: 0 8px 24px rgba(149, 117, 76, 0.08);`。
  - 主色調：珊瑚橘 `--coral: #ff8a65`、薄荷綠 `--mint: #7bc9b2`、檸檬黃 `--lemon: #ffd166`、晴空藍 `--sky: #7db8e8`、丁香紫 `--lilac: #b39ddb`。
- 頂部導航：像 App 一樣的**膠囊滑動標籤（Pill Tabs）**，大圓角、觸控回彈、選中時帶微陰影。

## 🛠️ 三大核心教具精緻擬物規格

### 🚂【教具一：日系繪本跳數小火車（Mini Express）】
- **純 SVG 可愛卡通蒸氣火車頭**：亮紅圓頂車身、黃銅復古車燈、煙囪冒著白色圓圓煙霧泡泡。
- **7 節彩色圓角木紋車廂**：
  - 每節車廂有雙小車輪、車廂連接勾，中央浮雕大字卡。
  - 在 360px~390px 手機寬度下，使用 `flex: 1 1 0; min-width: 0;` 緊湊排版，**7 節車廂 100% 入屏**（495 ➔ 500 ➔ 505 ➔ 510 ➔ 515 ➔ 520 ➔ 525），字體 10px~11px，絕不爆版、絕無捲軸！
- **純 SVG 拋物線跳數弧線與插旗**：
  - 點擊「發動跳數小火車 ▶」，車頭噴氣，拋物線弧線動態繪製，上方標示 `+5` 跳數旗幟！
  - 破招演繹卡片彈出：「495 個位 5+5 滿十進一，十位 9+1 再滿十進一，連進兩位跨整百變 500！」。
- 支援切換按鈕：【模式 A：+5 跨整百（495➔525）】與【模式 B：+10 跨整千（1980➔2020）】。

### 🃏【教具二：立體卡牌桌遊盤與雙比拼板（Card Deck & Dual Comparator）】
- **0, 7, 2, 8 立體厚卡牌**：
  - 擬物桌遊卡牌質感（圓角、頂部高光、邊框陰影、微浮起）。
- **雙槽對照（排最大 vs 排最小）**：
  - 上槽【🏆 最大四位數】：四個木紋金邊卡槽，點擊「排最大」依序飛入 `8`、`7`、`2`、`0`，破招提示：「高位填最大數字 ➔ 8720！」。
  - 下槽【🌱 最小四位數】：四個木紋銀邊卡槽，點擊「排最小」動態展示：千位若放 0 會彈出「🚫 首位不能為 0」可愛警示，挑選非零最小數 2 放入千位，排成 `2`、`0`、`7`、`8`！
  - **上下雙槽同時呈現在螢幕上對照！**
- **兩步驟完整大小比拼（杜絕漏做第 (2) 題！）**：
  - 【步驟 1】：4388 vs 4368。比到十位 8>6，4368 牌亮起薄荷綠勝出光暈，「4368 比較小！」。
  - 【步驟 2】：6008 vs 5999 vs 6100（三數比大！）。千位比拼 5999 淘汰翻轉打叉變灰；百位比拼 6100 大於 6008，6100 牌戴上金色皇冠！

### 📦【教具三：立體四艙位值與進位收納台（Place Value Vault）】
- **四個晶瑩立體收納箱**：【千位 (翡翠綠)】、【百位 (珊瑚紅)】、【十位 (蜜柑橙)】、【個位 (珍珠灰)】。
- **雙 0 占位演繹**：展示 5030 與 8006，百位與十位亮起可愛半透明虛線幽靈「0 占位」。
- **滿十進千動畫**：展示 8 千、14 百、7 十、3 一，點擊「滿十進千」，14 個百中的 10 個百動態融合成 1 個千位大金塊飛入千位箱，百位剩 4，千位變 9，結算為 `9473`！

## 🔒 程式碼質量與防錯規範
1. **嚴禁變數重複宣告**：同一 scope 內絕不可重複宣告 `const`。
2. **DOM 操作安全**：不要使用 `innerHTML +=` 破壞已綁定之 DOM 元素。
3. **完成後同步**：完成 `reports/g3_visual_samples_showcase.html` 後，必須同步複製至 `app/g3_showcase.html`。
