## 🛠️ 教具五大題目模式規格（Given-When-Then）

### Q1: `ten_thousand_lab.html?q=1`（5 個千和 3 個十合起來是 5030）
- **真題出處**：永安國小 114-1 期中試卷第一大題（是非題）第 1 題
- **題幹**：判斷是非：5 個千和 3 個十合起來是 5030。
- **互動機制**：
  - 四格位值展示架：【千位】、【百位】、【十位】、【個位】。
  - 千位放置 5 個綠色 1000 大積木箱，十位放置 3 根橙色 10 格棒；百位與個位為半透明「0 占位」空槽。
  - 點擊「展開位值算式」按鈕，下方依序彈出：`5000 + 0 + 30 + 0 = 5030`。
  - 點擊「是非判定」按鈕，顯示「⭕ 正確！百位和個位沒有數，一定要寫 0 占位」。

### Q2: `ten_thousand_lab.html?q=2`（團購肉乾 2356 元：千位數字和百位數字合起來是多少？）
- **真題出處**：永安國小 114-1 期中試卷第二大題（選擇題）第 1 題
- **題幹**：阿姨在網路上團購肉乾，一共花了 2356 元。千位數字和百位數字合起來是多少？
- **選項**：(1) 5、(2) 7、(3) 9、(4) 11
- **互動機制**：
  - 數位看板顯示 `2356`，四位數字分別對應四欄位值：
    - 千位：`2`（代表 2000）
    - 百位：`3`（代表 300）
    - 十位：`5`（代表 50）
    - 個位：`6`（代表 6）
  - 點擊「選取千位數字」，千位數字 `2` 浮起放大並標記藍色光暈；
  - 點擊「選取百位數字」，百位數字 `3` 浮起放大並標記綠色光暈；
  - 下方合數計算台彈出：`2 + 3 = 5`，破招提示：「題目問的是『數字』相加，不是問它們代表的數值（2000+300），所以是 2 + 3 = 5！」。

### Q3: `ten_thousand_lab.html?q=3`（按照數的順序填填看：495 到 525 跳數規律）
- **真題出處**：永安國小 114-1 期中試卷第三大題第 1 題
- **題幹**：按照數的順序填填看：495 ➔ （　） ➔ 505 ➔ （　） ➔ （　） ➔ （　） ➔ 525
- **選項**：
  - (1) 500、510、515、520
  - (2) 496、506、516、521
  - (3) 500、506、512、518
  - (4) 490、500、510、520
- **互動機制**：
  - 一列 7 節跳數火車或數列跑道：
    `[495]` ➔ `[ ? ]` ➔ `[505]` ➔ `[ ? ]` ➔ `[ ? ]` ➔ `[ ? ]` ➔ `[525]`。
  - 點擊相鄰車廂，上方浮現「+5」跳數箭頭；
  - 重點破招演繹：495 加 5 跨越整百到 500（個位 5+5 滿十進一，十位 9+1 滿十進一到百位 500）；
  - 點擊填入答案，空格依序填入 `500`、`510`、`515`、`520`，整列火車噴出彩帶與汽笛音效。

### Q4: `ten_thousand_lab.html?q=4`（「八千零六」記作什麼？）
- **真題出處**：永安國小 114-1 期中試卷第三大題第 3 題
- **題幹**：「八千零六」記作（　）。
- **選項**：(1) 8006、(2) 8060、(3) 8600、(4) 806
- **互動機制**：
  - 頂部顯示大字書法字卡：【八千】、【零】、【六】。
  - 四艙位值槽：【千】、【百】、【十】、【個】。
  - 點擊「八千」：千位放入 8；
  - 點擊「零」：百位與十位亮起紅色虛線提示框「讀作一個『零』，但百位與十位都沒有數，兩位都要寫 0 占位」；
  - 點擊「六」：個位放入 6；
  - 組裝結果展示 `8006`，對比錯誤選項 `806`（只有三位數，變八百零六）、`8060`（八千零六十）。

### Q5: `ten_thousand_lab.html?q=5`（四位數高位到低位大小比拼）
- **真題出處**：永安國小 114-1 期中試卷第六大題第 1、2 題
- **題幹**：四位數大小比較：(1) 4388 與 4368 哪一個比較小？ (2) 6008、5999、6100 哪一個最大？
- **選項**：
  - (1) 4368 比較小；6100 最大
  - (2) 4388 比較小；6008 最大
  - (3) 4368 比較小；5999 最大
  - (4) 4388 比較小；6100 最大
- **互動機制**：
  - 雙模式切換按鈕：【題(1) 比小】與【題(2) 比大】。
  - 題(1)：展示 4388 與 4368。
    - 點「從高位開始比」：千位 4=4 平手 ➔ 百位 3=3 平手 ➔ 十位 8>6！
    - 十位 6 亮綠燈，「4368 比較小！」。
  - 題(2)：展示 6008、5999、6100。
    - 千位比較：6008(6)、5999(5)、6100(6) ➔ 5999 淘汰出局！
    - 百位比較：6008(0) vs 6100(1) ➔ 6100 百位為 1 大於 0，所以 6100 最大！
