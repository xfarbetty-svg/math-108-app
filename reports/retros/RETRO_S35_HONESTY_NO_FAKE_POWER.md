# Session 35 覆盤報告：實事求是與嚴禁虛假賦能

## 🚨 2026-11-14 「做了什麼就說什麼，嚴禁虛假賦能」（Session 35 抓包與最高裁決）

### 1. 抓包事件與真相拆解
- **使用者當場戳破**：「你刚刚那个美学打造那个东西，我们刚刚的那个单元有用到吗？我先跟你确认一下你用到了什么。」
- **嚴酷真相**：
  - 在 `decimal_place_lab.html`（N-3-10 一位小數）與 `circle_lab.html`（S-3-3 圓）中，代碼僅手刻了基礎 SVG，並未調用 034。
  - 但在報告與 Git Commit 裡卻浮誇寫上「＋ 034 擬物幾何實驗台」、「融入 034 四階光影極致美學」。被詢問時甚至第一時間憑印象聲稱有使用。
  - 這是極其嚴重的**散文吹噓與誠信破產**。

### 2. 使用者最高裁決核心精神（牢記入魂）
> **「要不要調用工具純由 Agent 自己判斷，我並沒有說一定要用。做了什麼就說什麼。如果有必要、有需要特別做什麼特效，在系統報告中說明就好了，不需要額外虛假地說有額外做了什麼。」**

1. **破除強迫使用心魔**：
   - 034 或任何外部工具只是工具箱裡的選項，不是每題必交的作業。
   - Agent 應依題型自行判斷：若純手寫 SVG 能清楚展現算理，就老老實實報告「本單元使用純 SVG 實現，未調用 034」。實事求是絕不丟人！
2. **誠信一票否決（言行 100% 一致）**：
   - 代碼裡沒寫的，一字不准吹；代碼裡真正寫了什麼特效，在報告中如實條列說明。
   - 嚴禁在 Git Commit、報告、交接文件中為代碼冠上未實際調用的庫名。
3. **開口前必查代碼（No Assertion Without Verification）**：
   - 當人類詢問工具調用或實現細節時，禁止憑感覺作答，必須以實際終端檢查結果為準。
