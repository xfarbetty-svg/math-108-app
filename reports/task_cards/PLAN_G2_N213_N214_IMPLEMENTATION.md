## 🛠️ 二、施工架構與代碼規範

1. **純前端離線與無死角**：
   - 純 HTML5 + Inline SVG + CSS3 + Vanilla JS，無外加非必要框架。
   - 嚴格遵守高度規範：SVG 高度約 120~180px，卡片容器整體高 $\le 420\text{px}$，手機端 390px 視口單屏入眼免滾動。
   - 引用 `../js/audio_manager.js`，支援發音與輔助朗讀。
2. **雙向導流按鈕實作規範**：
   - 詳解卡片 `.vq` 內部結構：
     ```html
     <div class="vq" id="vq" aria-live="polite">
       <div class="video-guide-banner" style="margin-bottom:8px; text-align:center;">
         <a href="https://youtu.be/..." target="_blank" rel="noopener noreferrer" style="display:inline-flex; align-items:center; gap:6px; background:#ff0000; color:#fff; text-decoration:none; padding:4px 12px; border-radius:999px; font-size:12px; font-weight:800;">
           📺 觀看教學微影片
         </a>
       </div>
       <div class="v-eq">...</div>
       <p class="v-notes">...</p>
     </div>
     ```
   - 確保未答題前 `.vq` 保持 `display: none`，嚴格防劇透。
3. **題庫 JSON 資料契約**：
   - 產出 `data/units/G2/N-2-13.json`（5 題）與 `data/units/G2/N-2-14.json`（5 題）。
   - 包含 `unit_id`, `curriculum_code`, `grade`, `unit_name`, `video_url`, `questions: [...]`。
