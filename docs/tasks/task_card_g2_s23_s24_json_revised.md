## S-2-3 題目規格 (5 題)
- **Q01**: 基礎長度測量（鉛筆一端對準刻度「0」，另一端對準刻度「8」，鉛筆長幾公分？-> 8公分）
- **Q02**: 非零起點長度計算（緞帶左端對準刻度「3」，右端對準刻度「10」，這條緞帶長幾公分？-> 7公分，算式 $10 - 3 = 7$）
- **Q03**: 直尺正確使用方法（下列哪一個敘述正確？-> 物體的一端要對準刻度「0」開始量）
- **Q04**: 線段繪製觀念（老師要求畫一條「5公分長」的直線，小華從刻度「2」開始畫，應畫到刻度幾？選項包含刻度5、刻度6、刻度7、刻度8 -> 刻度7）
- **Q05**: 迴紋針長度比較（甲迴紋針從刻度0量到4，長4公分；乙迴紋針從刻度2量到7，長5公分。哪一個比較長？相差幾公分？-> 乙比較長，相差1公分）

## S-2-4 題目規格（全面升級為 G2 周長與邊長高階題，5 題）
- **Q06**: 三角形邊長與周長（測量一個三角形，三條邊分別長 3 公分、4 公分、5 公分，這個三角形的周界長度（周長）是多少公分？-> 12公分，算式 $3 + 4 + 5 = 12$）
- **Q07**: 正方形邊長特性與周長（一個正方形的每條邊都是 4 公分長，正方形四條邊都一樣長，它的周長是多少公分？-> 16公分，算式 $4 + 4 + 4 + 4 = 16$）
- **Q08**: 長方形對邊等長與周長（一個長方形的長邊是 5 公分，短邊是 3 公分。因為對面的邊一樣長，請問它的四條邊合起來（周長）是多少公分？-> 16公分，算式 $5 + 3 + 5 + 3 = 16$）
- **Q09**: 多邊形邊長走一圈周長（一個正五邊形的每一條邊都是 2 公分，小螞蟻沿著花圃外圍走完一圈，總共走了多少公分？-> 10公分，算式 $2 + 2 + 2 + 2 + 2 = 10$）
- **Q10**: 周長展開為直線比較（把一個每邊長 3 公分的正方形（周長 $3\times 4 = 12$）和一個長 4 公分、寬 2 公分的長方形（周長 $(4+2)\times 2 = 12$）的邊界剪開拉成一條直線，哪一個展開後的直線比較長？-> 一樣長，都是12公分）
