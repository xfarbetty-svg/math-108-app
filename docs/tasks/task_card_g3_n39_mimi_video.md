## 1. 🎯 單元目標與概念痛點解析 (Misconception Busters)

* **核心算理目標**：
  1. 理解「平分」是分數的先決條件（每份大小必須完全一樣）。
  2. 正確建立「分母代表全部平分成幾份（樓下）」、「分子代表取了幾份（樓上）」的直覺對應。
  3. 建立「$\frac{2}{4}$ 是 2 個 $\frac{1}{4}$ 的累加」，而非單純兩個數字的無意義組合。
* **學生常見迷思坑洞 (Pitfalls)**：
  - **非平分迷思**：只要切開幾塊就當成幾分之一，忽略面積必須相等。
  - **整數偏誤**：看到 $\frac{1}{4}$ 誤以為有「4 個」，無法理解這是不滿 1 個的「部分量」。
  - **上下混淆**：記不住誰在上、誰在下，容易把「四分之一」寫成 $\frac{4}{1}$。

## 2. 🐰 咪咪人設與角色視覺狀態 (純 SVG 動態表情)

* **角色視覺風格**：日系繪本純向量扁平 SVG，溫潤萌系、高辨識度（白兔體態、粉紅耳窩、靈動大眼）。
* **四大核心 SVG 狀態類別**：
  1. `state-normal`（開心打招呼）：雙耳直立微晃，眼睛水汪汪，右手向觀眾揮手。
  2. `state-confused`（困惑垂耳）：雙耳呈 45 度垂落，眼睛變成圓滾滾的困惑點點眼，頭頂浮現旋轉問號（？）。
  3. `state-eureka`（恍然大悟）：雙耳瞬間豎起彈跳，頭頂亮起金黃色小燈泡（帶星芒光暈），眼睛笑成月牙彎。
  4. `state-happy`（歡慶指引）：雙手高舉歡呼，雙眼彎彎，引導指針指向下方的操作區。
