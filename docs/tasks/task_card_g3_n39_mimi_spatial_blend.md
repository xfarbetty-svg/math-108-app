# 任務卡：G3-N-3-9 情境劇院一體化舞台空間融合（消除相框割裂感）

## 核心問題與目標
使用者親自審視指正：「咪咪老師是在一個框框裡面，而不是跟黑板是在同一個場景裡面，他像兩個螢幕逗在的東西」。
本任務由**通道一（OpenCode CLI）工兵**實體帶手腳施工，目標：
徹底消除米米老師左側的獨立相框/螢幕感，改用高品質透明底圖（`mimi_transparent_1024.png`），讓米米老師自然踩在教室木地板上、投下真實接觸陰影，與黑板完全共享同一間教室空間！

---

## 施工規範與要求 (`app/scenes/g3_n39_theater/index.html`)

1. **角色底圖切換為透明精靈**：
   - 底圖來源改為 `assets_hosts/g3_mimi/textures/mimi_transparent_1024.png`。
   - 移除舊有為方形圖片設計的 `mask-image: radial-gradient(...)` 與方形裁剪邊界。
   - 確保米米身後直接透出教室米黃色牆面與光影，完全消除獨立小螢幕方框感。

2. **空間立體融合與地面接觸陰影**：
   - 調整 `.mimi-zone` 與 `.mimi-wrap`：
     - 米米老師的站立基底自然落於教室木質地板層（地板約在 `bottom: 0` 至 `26%` 區域）。
     - 於米米腳下增加自然且柔和的地面投影（例如在 `.mimi-zone` 底部加入橢圓形柔和陰影 `radial-gradient(ellipse, rgba(70,34,10,0.45) 0%, transparent 70%)`），使米米產生「真實踩在木地板上」的立體深度。
     - 保留微表情與自然呼吸動態（`.speaking`、`.cheer`、`.tilt`）。

3. **零遮擋與單屏緊湊（One-Screen Fit）**：
   - 水平分帶：米米佔 `left: 2%~36%`，講台微縮置於 `left: 28%~35%` 或與米米完美搭接，黑板由 `left: 37%` 開始，嚴格維持 **0% 物理重疊**，絕不遮擋老師臉部或黑板算式。
   - 手機端 390px 視口全屏入眼免滾動，無橫向溢出。

4. **驗收防錯守門**：
   - 施工完畢後，執行：`node tools/capture_theater_acts.js`
   - 確保四幕截圖 `reports/screenshots/theater_act{1..4}.png` 順利更新。
   - 必須確保 Exit Code 0，無任何語法報錯。
