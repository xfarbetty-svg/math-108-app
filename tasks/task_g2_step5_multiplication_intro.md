# 任務卡：Step 5 - G2-N-2-6 乘法啟蒙 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-6 乘法啟蒙（幾個幾、倍數、同數累加與乘號誕生）` 打造專屬的「四幕式物理概念小教室」：
1. 產出檔案：`app/components/g2_multiplication_intro_lab.html`
2. 路由更新：在 `app/shell.js` 的 `CONCEPT_COMPONENTS` 中註冊 `N-2-6`：
   ```js
   "N-2-6": "components/g2_multiplication_intro_lab.html",
   ```

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (盤子裝蘋果：幾個幾)**
   - 繪製純 SVG 可愛盤子與紅蘋果。
   - 提供按鈕或切換器調整「盤數」(1~5 盤) 與「每盤數量」(2~4 顆)。
   - 清晰醒目展示乘法核心語言：
     - 例如 3 盤每盤 4 顆 ➔「4 的 3 倍」、「3 個 4」、「4 有 3 個」。
     - 點選盤子或按鈕時，即時動態更新畫面與算理氣泡，並調用 `AudioManager.play("4的3倍, 就是3個4, 一共有12顆蘋果")`。

2. **Act 2: 物理探索器 (連加到乘法的魔法誕生)**
   - 視覺化排開盤子與蘋果。
   - 點擊「展開連加」：盤子下方依序浮現連加算式（例如 `4 + 4 + 4 = 12`）。
   - 點擊「魔法變身」按鈕：
     - 動態動畫：加號 `+` 旋轉 45 度變身為乘號 `×`！
     - 算式濃縮轉化為 `4 × 3 = 12`。
     - 彩色標籤標註各部件名稱與意義：
       - `4` (被乘數)：每盤有 4 顆
       - `× 3` (乘數)：有 3 盤
       - `= 12` (積)：全部有 12 顆
     - 語音播放引導：「加號轉一轉變成乘號，3個4寫成 4乘以3等於12」。

3. **Act 3: 規律大發現 (青蛙跳跳階梯 / 倍數數線)**
   - 設計數線與可愛綠色小青蛙。
   - 可選「2的倍數」、「3的倍數」或「5的倍數」。
   - 點擊「跳一下」按鈕，青蛙跳出弧線軌跡：
     - 落地在 3, 6, 9, 12... 並在數線上方累積拋物線。
     - 下方即時點亮乘法階梯：`3 × 1 = 3` ➔ `3 × 2 = 6` ➔ `3 × 3 = 9` ➔ `3 × 4 = 12`。
     - 點出規律：「每一次跳躍都多 3，這就是倍數與乘法的規律！」

4. **Act 4: 小小挑戰賽 (乘法生活辨識挑戰)**
   - 提供 3 題生活乘法情境選擇題（例如：一輛三輪車有 3 個輪子，4 輛三輪車共有幾個輪子？一盒彩色筆有 5 枝，3 盒共有幾枝？）。
   - 辨識算式意義（如：是 3×4 還是 4×3？連加算式是？）。
   - 點擊選項即時判定，正確綠色高亮，語音正向反饋；錯誤橘色提示並引導。

## 硬性品質標準
- 手機視口 390px 寬度 100% 入屏，零橫向溢出 (`overflow-x: hidden`)。
- 操作區 stage 高度 $\le 420\text{px}$，全屏總高 $\le 740\text{px}$ 免滑動。
