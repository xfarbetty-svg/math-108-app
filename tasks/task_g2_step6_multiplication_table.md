# 任務卡：Step 6 - G2-N-2-7 九九乘法表 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-7 九九乘法表（二到九的乘法、點子矩陣陣列、斜對角對稱規律、乘法歌）` 打造專屬的「四幕式物理概念小教室」：
1. 產出檔案：`app/components/g2_multiplication_table_lab.html`
2. 路由更新：在 `app/shell.js` 的 `CONCEPT_COMPONENTS` 中註冊 `N-2-7`：
   ```js
   "N-2-7": "components/g2_multiplication_table_lab.html",
   ```

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (點子矩陣探險 / 陣列框選器)**
   - 繪製純 SVG 點子陣列（最大 9×9 網格），提供 Row (行: 1~9) 與 Col (列: 1~9) 調整按鈕或滑桿。
   - 動態框選高亮對應區域的點子（例如 3 行 4 列 = 12 顆點子）。
   - 展示雙向算理：
     - 橫看：3 行，每行 4 顆 ➔ `4 × 3 = 12`
     - 直看：4 列，每列 3 顆 ➔ `3 × 4 = 12`
   - 提供「旋轉 90 度」動畫按鈕，讓孩子直觀看見點子總數不變！
   - 調用 `AudioManager.play("3行4列共有12個點, 橫看直看總數都一樣")`。

2. **Act 2: 物理探索器 (九九乘法大棋盤 / 斜對角對稱之鏡)**
   - 繪製 9×9 緊湊乘法表格。
   - 棋盤中心貫穿一條金色斜對角線（平方數：1×1, 4, 9, 16, 25, 36, 49, 64, 81）。
   - 點擊任意一格（例如 `3 × 7 = 21`）：
     - 該格與對稱格 `7 × 3 = 21` 同時高亮，並呈現對稱光芒連線。
     - 氣泡說明：「3×7=21 和 7×3=21 對稱，積都是 21！」
     - 語音播放說明乘法的斜對角對稱規律。

3. **Act 3: 規律大發現 (滾輪速算九九歌 / 節奏卡片)**
   - 提供 2~9 的「段數標籤切換」（2的段、3的段……9的段）。
   - 選定某段（例如 5 的段）：
     - 排列出 5×1 到 5×9 的九張日系卡片。
     - 提供「自動朗讀」與點擊翻牌功能，卡片依序翻轉出結果，高亮顯示，並伴隨差值氣泡每次 `+5`。
     - 使用 `AudioManager.play` 朗讀該段乘法口訣（如「五一得五、五二一十、五三一十五...」）。

4. **Act 4: 小小挑戰賽 (九九乘法神算手)**
   - 3 道九九乘法互動挑戰題（含填空如 `6 × ▢ = 42` 或直接計算如 `8 × 7 = ?`）。
   - 選項按鈕即時判定反饋，正確綠色慶祝，錯誤提示再想想。

## 硬性品質標準
- 手機視口 390px 寬度 100% 入屏，零橫向溢出 (`overflow-x: hidden`)。
- 操作區 stage 高度 $\le 420\text{px}$，全屏總高 $\le 740\text{px}$ 免滑動。
- 強制引入 `<script src="../js/audio_manager.js"></script>` 並調用 `window.AudioManager.play()`，禁用 `speechSynthesis`。
- 暴露 `window.G2_LAB_SELFTEST` 包含 `switchAct`、`reset`、`state`。
