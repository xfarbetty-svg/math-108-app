# 任務卡：Step 15 - G2-N-2-14 時間（年、月、星期、日） 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-14 時間（年、月、星期、日、大月小月拳頭歌、月曆查閱、一星期7天、連續日期）` 打造專屬的「四幕式物理概念小教室」：
1. 產出檔案：`app/components/g2_calendar_lab.html`
2. 路由更新：在 `app/shell.js` 的 `CONCEPT_COMPONENTS` 中註冊 `N-2-14`：
   ```js
   "N-2-14": "components/g2_calendar_lab.html",
   ```

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (魔法年曆翻牌箱 / 12個月份大點名)**
   - 繪製純 SVG 擬物化月曆卡片。
   - 提供 1~12 月切換按鈕，點擊月份動態翻牌：
     - 大月（1, 3, 5, 7, 8, 10, 12月）：標註「大月 31 天」，高亮金色。
     - 小月（4, 6, 9, 11月）：標註「小月 30 天」，高亮藍色。
     - 2 月：標註「平年 28 天 / 閏年 29 天」，高亮紫色。
     - 調用 `AudioManager.play("一年有12個月, 31天的是大月, 30天的是小月, 二月最特別")`。

2. **Act 2: 物理探索器 (拳頭大月小月記憶神器)**
   - 繪製可愛握拳的純 SVG 拳頭圖（清楚畫出凸起關節與凹陷指縫）：
     - 凸起處：1月(31)、3月(31)、5月(31)、7月(31)、8月(31)、10月(31)、12月(31) ➔ 大月！
     - 凹陷處：2月(28/29)、4月(30)、6月(30)、9月(30)、11月(30) ➔ 小月！
   - 提供「點念口訣」按鈕，引導指針依序敲擊各位置並朗讀「一月大、二月小、三月大、四月小...」。

3. **Act 3: 規律大發現 (月曆神探 / 星期週期與跨日標尺)**
   - 呈現一張精緻的 7×5 月曆格子（星期日到星期六）。
   - 兩大發現展示：
     - ① **+7 規律**：直向同一行，下一個星期的同一天剛好是日期數字 `+7`！
     - ② **連續區間**：點選起始日與結束日（如 5月10日到 5月16日），月曆亮起彩色緞帶條，直觀數出經過了幾天。
   - 點選卡片高亮說明，並調用 `AudioManager.play` 語音導覽。

4. **Act 4: 小小挑戰賽 (時間神曆大考驗)**
   - 3 題月曆生活題（辨識小月、看月曆找星期幾、算大月數量等）。
   - 選項按鈕即時判定反饋，正確綠色慶祝，錯誤給予拳頭口訣提示，語音正向鼓勵。

## 硬性品質標準
- 手機視口 390px 寬度 100% 入屏，零橫向溢出 (`overflow-x: hidden`)。
- 操作區 stage 高度 $\le 420\text{px}$，全屏總高 $\le 740\text{px}$ 免滑動。
- 強制引入 `<script src="../js/audio_manager.js"></script>` 並調用 `window.AudioManager.play()`，禁用 `speechSynthesis`。
- 暴露 `window.G2_LAB_SELFTEST` 包含 `switchAct`、`reset`、`state`。
