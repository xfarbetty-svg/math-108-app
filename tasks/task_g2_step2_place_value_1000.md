# 任務卡：Step 2 - G2-N-2-1 一千以內的數 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-1 一千以內的數` 打造專屬的「四幕式物理概念小教室」：
產出檔案：`app/components/g2_place_value_1000_lab.html`

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (千/百/十/個位值結構)**
   - 繪製純 SVG 擬物化積木：1個千位大立方體 (1000)、百格板 (100)、十格條 (10)、個別小方塊 (1)。
   - 點擊「百/十/個」標籤可高亮對應積木與數量關係（10個一是1個十、10個十是1個百、10個百是1個千）。
   - 語音提示說明位值層級。

2. **Act 2: 物理探索器 (十百成千拖曳堆疊融合)**
   - 物理操作舞台：左側為「百格板發放區」，右側為「千位收集箱」。
   - 真實指針事件監聽（`pointerdown`, `pointermove`, `pointerup`, `setPointerCapture`），支援觸控與滑鼠拖曳。
   - 拖曳百格板進入收集箱磁吸貼齊，收集箱累計顯示目前百格數量（100, 200, 300...）。
   - 當拖入滿 10 塊（1000）時，觸發動畫特效：10 塊百格板瞬間合體變形為「✨ 金色 1000 立方體 ✨」，氣泡彈出提示「10 個百就是一千！」，語音朗讀「太棒了！10 個 100 就是 1000！」。

3. **Act 3: 規律大發現 (位值計數器與數線定位)**
   - 提供百位、十位、個位的 `+` 與 `-` 按鈕（如百位3、十位4、個位5 ➔ 345）。
   - 中間動態顯示對應的積木組合與大國字「三百四十五」。
   - 下方提供 0~1000 迷你數線，隨數字變化即時平滑位移指示標針，直觀感受數值在千以內的距離感。

4. **Act 4: 小小挑戰賽 (積木辨識互動題)**
   - 隨機或循序出 3 道題（例如顯示 4 個百、2 個十、6 個一，問代表多少？）。
   - 4 個選項按鈕點擊判定，答對標綠並彈出慶祝氣泡，答錯標紅並給出解析提示。
   - 全程連動 `speakText`（調用 `AudioManager.play`）。

## 硬性品質標準
- 手機視口 390px 寬度 100% 入屏，零橫向溢出 (`overflow-x: hidden`)。
- 操作區 stage 高度 $\le 420\text{px}$，全屏總高 $\le 740\text{px}$ 免滑動。
- 強制引入 `<script src="../js/audio_manager.js"></script>` 並調用 `window.AudioManager.play()`，禁用 `speechSynthesis`。
- 暴露 `window.G2_LAB_SELFTEST` 包含 `switchAct`、`reset`、`state`。
