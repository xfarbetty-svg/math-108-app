# 任務卡：Step 11 - G2-N-2-9 分裝與平分 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-9 分裝與平分（分裝/包含除連減、平分/等分除輪流分一顆、分裝與平分對照、除法前置體驗）` 打造專屬的「四幕式物理概念小教室」：
1. 產出檔案：`app/components/g2_division_intro_lab.html`
2. 路由更新：在 `app/shell.js` 的 `CONCEPT_COMPONENTS` 中註冊 `N-2-9`：
   ```js
   "N-2-9": "components/g2_division_intro_lab.html",
   ```

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (糖果物理分裝機 / 包含除連減體驗)**
   - 繪製 12 顆可愛 SVG 糖果。
   - 設定「每 3 顆裝一袋」：
     - 提供「裝一袋」按鈕，點擊一次 3 顆糖飛入新袋子中，上方糖果扣除 3 顆。
     - 旁白動態顯示連減過程：`12 - 3 = 9` ➔ `9 - 3 = 6` ➔ `6 - 3 = 3` ➔ `3 - 3 = 0`。
     - 總結面板：「12 顆糖果，每 3 顆裝一袋，可以裝成 4 袋！剛好分完！」
     - 調用 `AudioManager.play("12顆糖果, 每3顆裝一袋, 可以裝成4袋, 這就是分裝")`。

2. **Act 2: 物理探索器 (一人分一顆 / 等分除公平秤)**
   - 繪製 12 顆紅蘋果與 3 個可愛盤子（或小動物）。
   - 提供「輪流分一顆」按鈕：
     - 點擊按鈕，3 顆蘋果分別飛入 3 個盤子中（每人多 1 顆）。
     - 分 4 輪分完，每個盤子裡整齊放著 4 顆蘋果。
     - 總結面板：「12 顆蘋果平分給 3 人，每人分到 4 顆！大家都一樣多！」
     - 體會輪流公平分的動作。

3. **Act 3: 規律大發現 (分裝 vs 平分 雙面對照鏡)**
   - 雙欄對比卡片：
     - 【分裝 (包含除)】：知道「每袋有幾個」，問「可以裝幾袋？」
     - 【平分 (等分除)】：知道「有幾個人要分」，問「每人分到幾個？」
   - 點選卡片高亮圖解，並調用 `AudioManager.play` 語音導覽。

4. **Act 4: 小小挑戰賽 (公平分糖大師)**
   - 3 題生活情境互動題（例如：「15 顆草莓，每 5 顆裝一盤，可以裝幾盤？」、「16 枝彩色筆，平分給 4 個人，每人得幾枝？」、「20 顆彈珠，每 4 顆裝一包，是分裝還是平分？」）。
   - 選項按鈕即時判定，正確綠色慶祝，錯誤給予分裝提示，語音正向鼓勵。
