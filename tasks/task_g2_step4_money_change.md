# 任務卡：Step 4 - G2-N-2-5 幣值與錢幣換算 概念小教室

## 任務目標
基於 `app/components/g2_template_lab.html` 黃金樣板，為 108 課綱二年級單元 `G2-N-2-5 幣值與錢幣換算（100元、500元、1000元）` 打造專屬的「四幕式物理概念小教室」：
1. 產出檔案：`app/components/g2_money_change_lab.html`
2. 路由更新：在 `app/shell.js` 的 `CONCEPT_COMPONENTS` 中註冊 `N-2-5`：
   ```js
   "N-2-5": "components/g2_money_change_lab.html",
   ```

## 課綱教學標準與四幕設計要求
1. **Act 1: 觀念大解剖 (新台幣面額大解剖)**
   - 繪製純 SVG 擬物化新台幣：
     - 紙鈔：1000元（藍色）、500元（咖啡棕色）、100元（紅色國父鈔票）。
     - 硬幣：50元（金色立體）、10元（銀色）、5元（小銀色）、1元（銅色）。
   - 點擊鈔票或硬幣高亮並展示等價關係（例如：1張1000元 = 2張500元 = 10張100元；1枚50元 = 5個10元 = 50個1元）。
   - 語音提示說明面額與換算關係。

2. **Act 2: 物理探索器 (自動換錢機 / 撲滿兌換)**
   - 舞台設計：左側「錢包與零錢箱」，中央「自動換幣機」，右側「兌換出鈔口」。
   - 真實指針事件監聽（`pointerdown`, `pointermove`, `pointerup`, `setPointerCapture`），支援觸控與滑鼠拖曳。
   - **兌換模式 1**：拖曳 10 張 100 元進換幣機 ➔ 機器發光並發出音效，吐出一張全新「1000 元大鈔」！
   - **兌換模式 2**：拖曳 5 張 100 元進換幣機 ➔ 吐出一張「500 元鈔票」！
   - **兌換模式 3**：拖曳 1 張 1000 元進去 ➔ 找開換出 2 張「500 元」或 10 張「100 元」！

3. **Act 3: 規律大發現 (超市聰明付錢法)**
   - 模擬超市買文具/玩具情境（例如價格 365 元）。
   - 提供「最少鈔票硬幣付法」智慧引導：
     - 百位：300元 ➔ 用 3 張 100 元。
     - 十位：60元 ➔ 用 1 個 50 元 + 1 個 10 元。
     - 個位：5元 ➔ 用 1 個 5 元。
   - 點擊「顧客拿 500 元付款」按鈕，動態演示找零算式：500 - 365 = 135 元，出鈔口吐出 1張100 + 3個10 + 1個5元找零。

4. **Act 4: 小小挑戰賽 (收銀員找零挑戰)**
   - 提供 3 題付錢與找零互動情境題。
   - 選擇正確面額組合，即時答題判定，答對綠色慶祝，連動 `AudioManager.play` 曉臻高音質語音反饋。

## 硬性品質標準
- 手機視口 390px 寬度 100% 入屏，零橫向溢出 (`overflow-x: hidden`)。
- 操作區 stage 高度 $\le 420\text{px}$，全屏總高 $\le 740\text{px}$ 免滑動。
- 強制引入 `<script src="../js/audio_manager.js"></script>` 並調用 `window.AudioManager.play()`，禁用 `speechSynthesis`。
- 暴露 `window.G2_LAB_SELFTEST` 包含 `switchAct`、`reset`、`state`。

```bash
node tools/verify_g2_concept_labs.js --unit g2_money_change_lab.html
```
